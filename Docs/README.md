# Docs

Project documentation organized by domain.

- `architecture`: high-level design and dependency rules.
- `ml`: Machine Learning objectives and metrics.
- `demo`: demo script and presentation flow.
- `VALIDATION_GUIDE.md`: teacher validation checklist and commands.

Detailed module documentation lives beside each mini-project, for example `Backend/TalentBridgeAPI/README.md`, `Frontend/TalentBridgeWeb/README.md`, `NLP/CVExtraction/README.md`, and `Recommendation/JobRecommendation/README.md`.
